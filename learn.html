Project Ideas & Code Exercises

Here are some coding exercises and projects to practice what you're learning.

  • Ascii Name: Output your name in large letters with the asterisk character * as the lines for the characters
  • Ascii Clock: Create a program that prints out a picture of an analog clock
  • Chatbot: Ask a user how their day is, then output different responses based off the input.
  • Rock Paper Scissors Game
