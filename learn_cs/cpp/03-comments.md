
Following code can very difficult, so comments are used.
Comments are not executed as code and they act as notes to programmers to explain how the code works.
They are marked by // or /*.

// 2 slashes mark a single line comment.
/* a slash and an asterisk mark a multi-line comment and it must be closed by */

```cpp
int main() {
    //This is a single line comment
    /*
    This comment
    can have
    many lines
    Just remember to clost it
    */
}
```
